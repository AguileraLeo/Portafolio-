Portafolio Web Profesional Autoadministrable
Descripción General

Este proyecto corresponde a un Portafolio Web Profesional Autoadministrable desarrollado como parte de una evaluación académica orientada al área de Desarrollo y Diseño Web con apoyo de Inteligencia Artificial.

El sistema fue diseñado utilizando una arquitectura Full Stack basada en PHP y MySQL, complementada con Bootstrap, CSS avanzado y JavaScript para ofrecer una experiencia visual moderna, limpia y profesional.

El objetivo principal del proyecto es presentar información profesional del estudiante, incluyendo biografía, habilidades técnicas, tecnologías dominadas, proyectos desarrollados y un panel administrativo para la gestión dinámica del contenido.

Objetivos del Proyecto
Desarrollar un portafolio web profesional responsive.
Implementar un sistema autoadministrable conectado a MySQL.
Aplicar principios modernos de UI/UX Design.
Incorporar una estética visual minimalista basada en Soft UI.
Integrar formularios, autenticación y gestión dinámica de contenido.
Preparar el proyecto para funcionamiento local y despliegue en servidor externo.
