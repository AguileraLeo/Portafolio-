- CSS personalizado

INSTALACIÓN EN XAMPP

1. Copia la carpeta "portfolio_estudiante" dentro de:
   C:\xampp\htdocs\

2. Abre XAMPP y activa:
   - Apache
   - MySQL

3. Entra a phpMyAdmin:
   http://localhost/phpmyadmin

4. Importa la base de datos:
   - Clic en "Importar"
   - Selecciona el archivo:
     portfolio_estudiante/database/sql_setup.sql
   - Clic en "Continuar"

5. Abre el proyecto en el navegador:
   http://localhost/portfolio_estudiante/
