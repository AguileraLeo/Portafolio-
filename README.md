# Portafolio Web Profesional Autoadministrable

Proyecto académico y profesional desarrollado utilizando PHP, MySQL, Bootstrap, JavaScript y CSS avanzado, enfocado en la creación de un portafolio web moderno, responsive y autoadministrable.

---

## Descripción

Este proyecto corresponde al desarrollo de un sistema web orientado a la presentación profesional de un estudiante del área informática, incorporando una interfaz moderna basada en principios de UI/UX Design y Soft UI.

El sistema permite administrar dinámicamente contenido como:

* biografía
* habilidades
* tecnologías
* proyectos
* mensajes de contacto

mediante un panel administrativo conectado a base de datos MySQL.

---

# Objetivos del Proyecto

* Desarrollar un portafolio profesional responsive.
* Aplicar tecnologías Full Stack.
* Implementar autenticación administrativa.
* Gestionar contenido dinámicamente mediante MySQL.
* Integrar principios modernos de diseño UI/UX.
* Preparar el sistema para despliegue en servidor externo.
